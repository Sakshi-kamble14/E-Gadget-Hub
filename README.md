# ♻️ E-Waste Management System

A full-stack web application designed to promote responsible electronic waste management by connecting users with e-waste collection, recycling, and disposal services.

The platform allows users to register their electronic waste, schedule pickups, track collection requests, and monitor their recycling activities.

The system also provides an administrative dashboard for managing users, e-waste records, pickup requests, recycling activities, and collection centers.

---

## 🌱 About the Project

Electronic waste is one of the fastest-growing waste streams in the world. Improper disposal of electronic devices can cause environmental pollution and health risks.

The **E-Waste Management System** provides a digital platform to simplify the process of:

- Collecting electronic waste
- Scheduling e-waste pickups
- Managing collection requests
- Tracking recycling activities
- Connecting users with collection centers
- Monitoring e-waste statistics
- Promoting responsible recycling

---

# 🚀 Features

## 👤 User

Users can:

- Register an account
- Login securely
- Manage their profile
- Add e-waste items
- Select e-waste categories
- Specify quantity/weight
- Schedule a pickup
- Select a collection location
- Track pickup status
- View previous pickup requests
- View recycling history
- Cancel pickup requests
- Receive pickup status updates

---

## 👨‍💼 Administrator

Administrators can:

- Login securely
- View dashboard statistics
- Manage registered users
- Manage e-waste records
- Manage pickup requests
- Approve/reject pickup requests
- Update pickup status
- Manage collection centers
- Manage recycling information
- View system-wide statistics
- Monitor collected e-waste
- View reports and analytics
